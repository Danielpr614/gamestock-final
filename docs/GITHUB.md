# Repositório do GameStock Final

Repositório público: https://github.com/Danielpr614/gamestock-final

O código está na raiz do repositório, junto com README, SQL, imagens e documentação. As contas incluídas são fictícias para avaliação. A configuração local e os dados pessoais do computador do aluno não fazem parte da publicação.

## Baixar e executar

1. Abra o endereço acima e clique em **Code → Download ZIP**.
2. Extraia e renomeie `gamestock-final-main` para `gamestock_final`.
3. Copie para `C:\xampp\htdocs\gamestock_final`.
4. Siga a instalação do README: iniciar XAMPP, importar `database/instalar.sql` em uma base nova e conferir a porta do banco.
5. O GitHub armazena o projeto; PHP e MySQL precisam ser executados pelo XAMPP. GitHub Pages não executa este sistema PHP.

## Manter atualizado

Alterações feitas no computador não são enviadas automaticamente ao GitHub. Após validar uma nova versão, faça commit e push pelo Git ou publique a atualização com a conexão autorizada do GitHub.

Não publique `config/local.php`, exportações com dados pessoais, logs, pastas de runtime nem ZIPs de versões antigas. O SQL distribuído é o de demonstração.

## Entrega

Compartilhe com o professor o endereço do repositório público. O README contém instalação, contas de teste, regras, diagramas, funcionalidades e prints. O envio do link ao professor deve ser feito pelo aluno na plataforma da faculdade.
